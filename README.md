GrowPath
GrowPath is an AI-powered career and learning roadmap platform designed to help students become job-ready.
Students can select their career goal, current level, and target, and GrowPath provides a structured learning path covering skills, learning resources, practice, projects, progress, and certificates.
🚀 Features
🎯 Career goal selection
🗺️ Personalized learning roadmap
📚 Learning resources
💻 Practice and projects
📊 Progress tracking
🏆 Certificate tracking
🤖 AI career assistant
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB Atlas, Mongoose
Tools: Git, GitHub, VS Code
🔄 How It Works
Login → Career Setup → Select Goal → Generate Roadmap → Learn → Practice → Build Projects → Track Progress → Become Job-Ready 🚀
📌 Project Status
GrowPath is currently under development. The core frontend, backend APIs, MongoDB integration, career setup, roadmap storage, and progress tracking are implemented.
Future plans include Gemini AI integration, YouTube learning recommendations, authentication, and an AI career assistant.
